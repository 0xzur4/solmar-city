Solmar is a 2D top-down open-world crime game set in a sun-soaked coastal city. Drive and steal cars, dodge the Solmar PD's wanted stars, roadblocks and police helicopter, run eleven story missions for the fixer Mara Voss, race checkpoints, wreck rival crews, take taxi fares and hunt ten hidden packages — all in plain HTML, canvas and WebAudio, no libraries and no network.

The city runs a full day cycle: bright day, golden hour, then night, when street lamps, headlights and neon signs take over. Repair your car at Mara's Garage, hide at the safehouse to lose the heat, and watch the wanted stars pulse as the chase heats up.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
