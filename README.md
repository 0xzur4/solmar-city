Solmar is a 2D top-down open-world crime game set in a sun-soaked coastal city. Drive and steal cars, dodge the Solmar PD's wanted stars, run six story missions for the fixer Mara Voss, and take taxi fares — all in plain HTML, canvas and WebAudio, no libraries and no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
